# 🚀 Agile Task Manager API
> **Software Engineering Lab Project** | Implementing Agile/Scrum Methodology.

---

## 📋 Project Overview
This project is a **RESTful API** designed for task management, built with **Node.js** and **Express**. The primary goal is to demonstrate core **Software Engineering** principles, including:
* **SDLC:** Software Development Life Cycle.
* **Version Control:** Advanced Git & GitHub workflows.
* **Agile Management:** Dividing work into iterative Sprints.

## 🔄 Sprint Management (Agile Roadmap)
We divided the project into **3 Strategic Sprints** for continuous delivery:

### 🔹 Sprint 1: Infrastructure & Environment
- **Goal:** Set up the development environment and Git synchronization.
- **Key Commands:** `npm init`, `git init`, `npm install`.

### 🔹 Sprint 2: Core Functionality (Read)
- **Goal:** Develop Data Models and GET endpoints to fetch tasks.
- **Key Commands:** `git branch`, `node index.js`, `git commit`.

### 🔹 Sprint 3: Final Integration (Write & Merge)
- **Goal:** Implement POST functionality and merge feature branches into Main.
- **Key Commands:** `git merge`, `git push origin main`, `git log`.
